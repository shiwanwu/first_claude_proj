# CPU IP 验证工程师 · 个人主页

个人品牌主页，展示专业技能、验证方法论与技术栈。

## 概览

一个具有芯片科技感风格的单页 HTML，用于快速建立专业形象，包含：

- **个人介绍** — 验证工程师背景与哲学
- **技术栈** — UVM / Formal / CPU 架构 / 脚本工具链
- **专业指标** — 测试用例量、覆盖率、Tape-out 经验
- **联系方式** — Email、电话、微信二维码、LinkedIn、GitHub

## 使用

直接打开 `index.html` 即可预览。如需发布：

```bash
# 修改个人信息
# 1. 替换 index.html 中的占位姓名、邮箱、手机号
# 2. 将微信二维码图片替换 qr-placeholder 区域
# 3. 更新 LinkedIn / GitHub 链接
```

## 技术栈

- 纯 HTML + CSS，零依赖
- 字体: Inter + JetBrains Mono
- 响应式布局，适配移动端
